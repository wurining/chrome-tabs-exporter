Chrome Tabs Exporter

Export open tabs and native tab groups to Markdown or JSON, and restore tabs from compatible JSON. File processing stays on your device.

将标签页与原生分组导出为 Markdown 或 JSON，也可以从兼容 JSON 恢复标签页，文件仅在本机处理。

Local exports / 本地导出

Select one or more normal windows, groups and individual tabs. Choose English or Simplified Chinese in Settings. Incognito windows and the extension's own pages are excluded.

勾选一个或多个普通窗口、分组和单个标签页；在设置中选择简体中文或英文。隐身窗口和本扩展自身页面均被排除。

Import JSON to preview and reopen URLs and groups in new windows or append them to the current window. Restoration visits those sites normally. Every feature is free; no file data is uploaded to the developer. Open source under MIT.

导入 JSON，预览后在新窗口恢复网址和分组，也可以追加到当前窗口。恢复会正常访问对应网站。全部功能免费，文件不上传给开发者，使用 MIT 许可证开源。

Install / 安装

Extract the release ZIP, open chrome://extensions, enable Developer mode and load the extracted folder. Requires Chrome 99+.

解压发布包，打开 chrome://extensions，启用开发者模式并加载解压文件夹。要求 Chrome 99 或更新版本。
